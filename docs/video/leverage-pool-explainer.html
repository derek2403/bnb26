How a two-token leverage pool works

This pool holds one asset, bNVDA, and splits its value between two tokens. Nobody borrows, and nobody has a debt.

The one rule: the stable side never changes in USD. So the leveraged side gets all of the pool's gain and all of its loss.

Use the walk-through first. Then try your own moves in the playground.

A forced exit. It cannot happen here, because no user has a debt.

Event log

    Why the leverage changes

    Leverage is pool value ÷ xNVDA part, and the sUSD part stays fixed in USD. When bNVDA rises, the xNVDA part grows faster than the pool, so leverage falls. When bNVDA falls, the xNVDA part shrinks faster than the pool, so leverage rises.

    The sell zone

    When leverage gets too high, the pool sells some bNVDA for USDC, a token worth 1.00 USD. The USDC stays in the pool, and it does not fall when the stock falls. This protects Bob and makes Alice's next loss smaller. The cost is a smaller recovery for Alice when the price rises again.

    How to read the tables

    The tables use three kinds of numbers.

    • A count tells how many tokens exist. Example: how many bNVDA the pool holds.
    • A price is the USD for one token. Example: USD per bNVDA.
    • A value is count × price. It is always in USD.

    Stock value
    bNVDA in pool × price. Only this part moves with the price.
    Pool value
    Stock value + USDC in pool.
    Bob and Alice
    Bob gets up to 100 USD of the pool value. Alice gets the rest.
    Leverage here
    Stock value ÷ Alice's part. A sale changes bNVDA into USDC. It does not change the pool value.
